Target Deployment: Vercel or Node.js Containerized Hosting
1. Executive Summary & Vision
1.1 Purpose
The objective of this project is to build a modern, serene, secure, and highly responsive professional website for Dr. Vandana Rajiv Chaudhary (drvandana.trinetralab.net). The web platform serves as a digital gateway designed around five core principles: Trust, Education, Confidentiality, Accessibility, and Conversion.
1.2 Strategic Intent
Unlike generic medical or clinical portals, the website is structured specifically for a mental health practice. It minimizes cognitive load for visitors experiencing emotional distress and establishes an ethical, calm, and welcoming digital space while streamlining appointment bookings and B2B/institutional workshop inquiries.
1.3 Key Technical Directive (Cursor AI Integration)
The architecture and codebase must be optimized for AI-assisted development using Cursor AI. This requires a modular design, strict TypeScript typing, isolated components, standardized layout primitives, and well-structured prompt context files (.cursorrules).

3.1 Strict Data Boundary Policy
No EHR/EMR Integration in Website Database: The website functions strictly as a public educational and appointment lead intake platform.
Zero Sensitive Health Information Collection: Web forms must explicitly state: "Please do not submit detailed medical or clinical history."
Third-Party Boundary: No client therapy notes, diagnostic records, or session transcripts shall ever touch or pass through the website database, analytics, or logging tools.

6.2 Data Model & Schemas (TypeScript / Zod)
Appointment Inquiry Schema
TypeScript
import { z } from "zod";
export const AppointmentSchema = z.object({
category: z.enum([
"adult_individual",
"child_adolescent",
"relationship_family",
"stress_wellness",
"follow_up"
], { required_error: "Please select a consultation category." }),
mode: z.enum(["in_person", "online"], { required_error: "Please select a preferred mode." }),
fullName: z.string().min(2, "Name must be at least 2 characters."),
phone: z.string().regex(/^[0-9+\s-]{10,15}$/, "Please enter a valid phone number."),
email: z.string().email("Please enter a valid email address."),
preferredTimeSlot: z.enum(["morning", "afternoon", "evening"]),
notes: z.string().max(300, "Notes cannot exceed 300 characters.").optional(),
privacyConsent: z.literal(true, {
errorMap: () => ({ message: "You must accept the privacy policy to proceed." }),
}),
});
export type AppointmentFormInput = z.infer<typeof AppointmentSchema>;
Workshop Inquiry Schema (Phase 2)
TypeScript
import { z } from "zod";
export const WorkshopInquirySchema = z.object({
organizationType: z.enum(["school", "corporate", "community", "other"]),
organizationName: z.string().min(2, "Organization name is required."),
contactPerson: z.string().min(2, "Contact person name is required."),
email: z.string().email("Invalid email address."),
phone: z.string().min(10, "Valid contact number is required."),
estimatedAudienceSize: z.string().optional(),
proposedDate: z.string().optional(),
message: z.string().min(10, "Please provide brief details about your workshop requirements."),
});
export type WorkshopInquiryInput = z.infer<typeof WorkshopInquirySchema>;
